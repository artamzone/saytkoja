Сделай современный адаптивный сайт-витрину для мастерской кожаных сумок ручной работы. Сайт не интернет-магазин: без корзины, без оплаты, без личного кабинета и без backend. Главная задача — красиво показать изделия и привести пользователя к мастеру через кнопку связи.
Перед началом работы просмотри все предоставленные фотографии и сначала составь краткую карту: какое фото лучше использовать для hero, категорий, карточек моделей и блока деталей. Не изменяй и не генерируй изображения без необходимости.
Используй стек:
- Vue 3
- Vite
- Vue Router
- Tailwind CSS v4
- lucide-vue-next для иконок
Сайт должен быть mobile-first, быстрым, легким и визуально премиальным.
Общий стиль:
- теплый светлый фон;
- крупная fashion-фотография;
- сочетание serif-заголовков и современного sans-serif текста;
- много воздуха;
- минимум декоративных элементов;
- без тяжелых анимаций;
- визуальный акцент на фотографиях изделий.
Используй такую палитру:
- background: #F5F0E8
- background-soft: #EDE4D8
- text: #171411
- text-secondary: #6B625A
- brown: #79553D
- red-accent: #B81E24
- blue-accent: #AFC8D8
- border: #D7CEC2
Для заголовков используй Cormorant Garamond или близкий serif-шрифт. Для основного текста — Manrope или похожий sans-serif.

Все изображения разместить в /public/images.
Важно:
- использовать реальные фотографии из папки assets/images, если они доступны;
- не генерировать placeholder-картинки, если реальные фото уже есть;
- сохранять исходное соотношение сторон;
- использовать object-cover только там, где кроп действительно нужен;
- на карточках допускать разные форматы фото;
- использовать lazy loading;
- добавить мягкий hover zoom;
- никакой агрессивной анимации.
Связь с мастером:
Сделать единый helper/utility для ссылки на Telegram или VK.
При нажатии с карточки изделия формировать сообщение:
Здравствуйте! Мне понравилось изделие "Название". Хотел(а) бы узнать подробнее.
Добавить в проект конфигурацию:
export const siteConfig = {
  telegram: '',
  vk: '',
  phone: '',
  brandName: ''
}
