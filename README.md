# Витрина кожаной мастерской

Vue 3, Vite, Vue Router, Tailwind CSS v4, lucide-vue-next. Без backend, оплаты и корзины.

## Запуск

`npm install`
`npm run dev`
`npm run build`
`npm run preview`

Локальный адрес: http://127.0.0.1:5173 (localhost может вести на другой IPv6-сервер).
Проверки: `node tests/smoke.mjs` при запущенном dev-сервере и установленном Google Chrome.

## Перед публикацией

- Заполнить `src/data/siteConfig.js`: название, полные HTTPS-ссылки Telegram/VK (для VK желательно vk.me), телефон, публичный домен.
- В `src/data/products.js` подтвердить названия, материалы, цвета, детали и наличие; добавить размеры и цены. Текущие названия — редакционные, цены по запросу, размеры не выдуманы.
- Добавить имя/историю мастера в `src/views/AboutView.vue`, подтвердить доставку в DeliveryView.vue, дополнить PrivacyView.vue юридическими сведениями.
- Заменить example.com в `public/sitemap.xml`, добавить Sitemap с абсолютным URL в `public/robots.txt`. В `index.html` обновить начальные title/OG и абсолютный og:image под бренд и домен.
- Для history-маршрутов настроить хостинг: неизвестные файловые пути перенаправлять на index.html (SPA fallback).
- До заполнения контактов CTA ведёт на /contacts, название изделия и текст сообщения сохраняются. Мессенджер не подменяется выдуманным аккаунтом. Возможность подстановки текста зависит от клиента мессенджера.
- Используются системные serif/sans-serif шрифты без внешних запросов. Можно подключить локальные лицензированные Cormorant Garamond/Manrope.
