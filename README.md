# Витрина кожаной мастерской

Vue 3, Vite, Vue Router, Tailwind CSS v4, lucide-vue-next. Без backend, корзины и оплаты.

## Запуск

- `npm install`
- `npm run dev` — локально: http://127.0.0.1:5173
- `npm run build` — сборка в `dist/`
- `npm run preview` — просмотр сборки

Проверки: `node tests/smoke.mjs` и `node tests/content.mjs` при запущенном dev-сервере и установленном Google Chrome.

## Как редактировать сайт

Все основные данные находятся в **`src/data/`**. Vue-компоненты менять не нужно.

- **Название и телефон:** `site.js`, поля `brandName`, `phone`. Здесь же знак бренда и подпись под ним.
- **Telegram/VK/MAX:** `site.js`, поля `telegram`, `vk`, `max`. Укажите полную HTTPS-ссылку; для VK предпочтительно `https://vk.me/…`. Пустые контакты не открывают пустые ссылки; если контактов нет, кнопка «Написать мастеру» отключена.
- **Email, город, адрес:** `site.js`, поля `email`, `city`, `address`. Необязательные поля можно оставить пустыми.
- **Тексты главной:** `content.js`, разделы `hero`, `collections`, `popular`, `quality`, `aboutPreview`, `contactCta`. Там же фото блоков, тексты остальных страниц, кнопок и подвала. Заголовки разделены на части для сохранения переносов и курсива.
- **Добавить изделие:** в `products.js` скопируйте один объект целиком, задайте уникальные `id` и `slug`, заполните название, описания, материал, `size`, `colors`, `images`. `category` — id из `categories.js`; `tags` — дополнительные категории (можно `[]`). `details` — особенности, `availability` — наличие. `cardColor` — точка на карточке (`red`, `blue` или пустая строка).
- **Скрыть изделие:** поставьте ему `visible: false`. Оно исчезнет из каталога, популярных, похожих и со страницы по прямой ссылке. Для главной включите `featured: true`; порядок соответствует порядку объектов в файле.
- **Изменить цену:** поле `price` нужного изделия в `products.js`, например `"от 12 000 ₽"`.
- **Категории:** `categories.js`: `id`, `title`, `subtitle`, `image`, `visible`. `visible: false` скрывает категорию из блоков и фильтров, но не скрывает её изделия.
- **Добавить фотографии:** положите файл в подходящую папку `public/images/products/`, `categories/`, `hero/`, `details/` или `lifestyle/`. В данных укажите путь без `public`, например `/images/products/new-bag.jpg`. Первая запись `images` — обложка. Одно фото можно использовать в нескольких блоках: копии не нужны. Папка `categories/` подготовлена для новых фото; текущие категории используют снимки изделий.
- **SEO:** `site.js`, раздел `seo` и поле `siteUrl`. Начальные метатеги сборки и метатеги страниц берут данные отсюда; названия внутренних страниц — `content.js`, раздел `seo`. После правок пересоберите сайт; при изменении SEO во время разработки перезапустите dev-сервер.

## Перед публикацией

- Заполните настоящие контакты и название в `site.js`.
- Подтвердите названия изделий, материалы, размеры, цены и наличие в `products.js`.
- В `content.js` добавьте историю мастера, подтвердите условия доставки и дополните юридический текст конфиденциальности.
- В `public/sitemap.xml` замените example.com настоящим доменом, в `public/robots.txt` добавьте абсолютный адрес Sitemap. Это технические файлы, они пока редактируются отдельно.
- Настройте на хостинге SPA fallback: маршруты страниц должны открывать `index.html`.

Все 26 оригинальных фотографий сохранены без обработки и дубликатов, изменено только расположение по папкам. Сообщение о выбранном изделии готовится автоматически, но не отправляется без действий пользователя; поддержка предзаполненного текста зависит от приложения мессенджера.
